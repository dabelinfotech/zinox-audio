Part 1 — Installation

7 sections

Before you start

One installer per platform sets up everything — the DAW plugin formats and the standalone app install together in a single run. You don't download or run anything separately for the two.

System requirements
WindowsWindows 10 or later, 64-bit
macOSmacOS 10.13 or later
FormatsVST3 (Windows & macOS) · Audio Unit (macOS) · Standalone app (Windows & macOS)
AudioMono or stereo, any sample rate
RightsAdministrator/admin password required for install (writes to a shared plugin folder)
Unsigned installerZinox Vocals isn't code-signed yet, so both operating systems will flag the installer the first time. This is expected — see the warning box in each platform's steps below for the exact click-through.

Installing on Windows

Run ZinoxVocals-Setup-1.0.0.exe and follow the wizard.

  1. Run the installer

    Double-click the .exe. Windows SmartScreen will likely say "Windows protected your PC" — click More info, then Run anyway. This appears because the installer isn't signed with a paid code-signing certificate, not because anything is wrong with it.

  2. Approve the admin prompt

    Installing into the shared VST3 folder needs administrator rights. Accept the UAC prompt to continue.

  3. Choose a desktop shortcut (optional)

    The one checkbox in the wizard adds a shortcut for the standalone app. The VST3 always installs regardless — there's no way to opt out of it on Windows.

  4. Finish

    The VST3 lands in C:\Program Files\Common Files\VST3\Zinox Vocals.vst3; the standalone app in C:\Program Files\Zinox Audio\Zinox Vocals\. The wizard offers to launch the standalone app immediately.

Installing on macOS

Run ZinoxVocals-Setup-1.0.0.pkg and follow the installer.

  1. Open the package

    Gatekeeper will refuse to open it normally, since it isn't notarized. Instead, Control-click (or right-click) the .pkg → Open, then confirm in the dialog that appears. You only need to do this once.

  2. Choose what to install

    The installer offers three components — VST3 Plugin, Audio Unit, and Standalone App — all checked by default. Leave them all checked unless you specifically don't use one of those formats.

  3. Enter your admin password

    Installing into the shared /Library plugin folders and /Applications needs it.

  4. Finish

    VST3 → /Library/Audio/Plug-Ins/VST3/. Audio Unit → /Library/Audio/Plug-Ins/Components/. Standalone → /Applications/Zinox Vocals.app.

Finding it in your DAW

Most DAWs pick up a new VST3 or AU automatically on the next launch. If Zinox Vocals doesn't show up in your plugin list, look for a manual rescan option — it's usually under a menu named something like Plugin Manager, Preferences → Plug-ins, or Rescan Plugins, depending on the DAW. Search for "Zinox" once the scan finishes.

Activating your license

Activation is entirely offline — there's no account to create and no internet connection required.

  1. Open the license panel

    Click the badge in the top-right of the plugin window (it reads TRIAL: N DAYS LEFT or UNLICENSED before you activate).

  2. Check the Machine ID

    The dialog shows this computer's Machine ID. If you bought a machine-locked key, this is the ID you'd have sent when purchasing — it has to match for that key to work here.

  3. Paste your license key

    Paste the key you were sent into the License key field and click ACTIVATE.

  4. Done

    A confirmation names who the copy is licensed to. The badge switches to LICENSED and stays that way — the key is saved and re-checked automatically every time the plugin loads, so you won't need to re-enter it.

Moving to a new machineAn unlocked key (not tied to a specific Machine ID) works on any computer you install Zinox Vocals on. A machine-locked key only activates on the machine it was issued for — contact support if you need it moved.

The free trial

Every install starts a genuine 7-day trial from first launch — full quality, every feature, nothing watermarked or held back. The badge tracks it:

TRIAL: 7D LEFT TRIAL: 1D LEFT TRIAL EXPIRED LICENSED

Once the 7 days are up without a license entered, the plugin stops processing audio — it outputs silence rather than degrading quality — and the window shows a "Free Trial Ended" screen with the license panel one click away. Entering a valid key at any point, during or after the trial, unlocks it permanently.

Uninstalling

Windows

Use Settings → Apps (or Control Panel → Programs and Features) and remove "Zinox Vocals" — the installer registers a proper uninstaller that removes both the VST3 and the standalone app.

macOS

The .pkg installer doesn't register an uninstaller (standard for macOS package installers). Remove it by deleting these three items directly:

  • /Library/Audio/Plug-Ins/VST3/Zinox Vocals.vst3
  • /Library/Audio/Plug-Ins/Components/Zinox Vocals.component
  • /Applications/Zinox Vocals.app

Part 2 — How It Works

6 sections

The window is laid out left to right in roughly the order the signal moves through it.

  • Header

    Bypass, the license badge, and the preset bar — previous/next arrows, a dropdown of every preset, and Save.

  • Left column

    Input trim, Denoise, and the Low Cut / High Cut filters — the "clean the source" stage, before anything shapes the tone.

  • Centre — tone row

    Low, Mid, High, and De-Ess.

  • Centre — dynamics row

    Control, Push, Saturate, and Output.

  • Right column

    The output meter, the limiter's ceiling and gain-reduction meter, and the oversampling selector.

  • Top bar (Standalone only)

    The Import / Play / Export file bar — absent when Zinox Vocals is loaded as a plugin inside a DAW, since the DAW already owns the audio transport.

The signal chain

Eight stages, always in this order, whether you're in a DAW or the standalone app.

  1. 01

    Denoise

    Learns the noise floor per frequency band during quiet parts, then subtracts it back out.

  2. 02

    Filters

    24 dB/octave low-cut and high-cut.

  3. 03

    Tone

    Low, Mid, and High bands.

  4. 04

    De-Ess

    Compresses only the sibilant band.

  5. 05

    Control

    The main compressor.

  6. 06

    Push

    A second, parallel compressor for density.

  7. 07

    Saturate

    Harmonic colour.

  8. 08

    Limit

    Look-ahead brickwall ceiling.

Import, play & export standalone only

The bar across the top of the standalone window, absent when running as a plugin inside a DAW.

  1. IMPORT

    Drag an audio file onto the bar, or click Import to browse. Supports WAV, AIFF, MP3, FLAC, OGG, and M4A.

  2. PLAY / STOP

    Loops the imported file through the live processing chain and out to your speakers. Turn any knob while it's playing and the change is audible within a single audio block — the same code path that would otherwise be reading a live microphone.

  3. EXPORT

    Bounces the imported file through your current settings and saves it as a new WAV file. This runs on a background thread with a progress dialog, and it's latency-compensated — the result is the same length and sample-aligned with the original, regardless of what oversampling or the limiter's look-ahead add internally.

A five-minute workflow

A sensible order to work through the chain on a fresh vocal take.

  1. Set Input

    Watch the OUT meter and set Input so the signal sits comfortably below clipping before anything else touches it.

  2. Clean it up

    Denoise for room tone or hiss, then Low Cut to remove rumble below the voice.

  3. Shape the tone

    Small moves on Low/Mid/High — a dB or two goes a long way at this range.

  4. Tame sibilance

    Bring De-Ess up only as far as the esses actually need it — overdoing it dulls the voice.

  5. Even it out

    Control for the main dynamic range, Push if it still needs more density and sustain.

  6. Add character, then catch the peaks

    A touch of Saturate for colour, Output to set the final level, and leave Limit engaged as a safety net.
