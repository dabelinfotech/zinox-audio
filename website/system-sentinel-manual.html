Starting a scan

02

  1. Open SystemSentinel

    Launch the app from your Start menu, Applications folder, or the portable executable.

  2. Confirm the detected computer model

    Check the device summary at the top of the dashboard to be sure the right machine was detected.

  3. Select Scan now

    The scan begins immediately and runs through five stages.

  4. Wait for the scan stages to complete

    System data → Power check → Disk health → Software logs → Fault review.

  5. Review the results

    Read the overall score first, then the individual component cards.

Automatic refresh The app refreshes its diagnostic data automatically during normal use, so you do not need to rescan constantly to keep readings current.

Understanding the report

03

Overall system status

The score summarizes the current health of the monitored components. A warning or critical status means the related evidence and recommended action should be reviewed.

Hardware health

SystemSentinel evaluates:

  • CPU load and temperature indicators
  • Memory pressure
  • Storage capacity and estimated drive health
  • Cooling and thermal load
  • GPU temperature indicators
  • Power and battery condition
  • Network errors

Software health

SystemSentinel evaluates:

  • Operating system updates
  • Drivers and peripherals
  • Startup programs
  • Security software status
  • Application crashes and hangs
  • Recent system or diagnostic logs
  • File-system warning indicators

Confirmed faults

Confirmed faults are current findings that exceed the diagnostic warning threshold. They are evidence-based indicators, not a substitute for a technician's physical inspection.

Future-fault forecast

Forecast percentages are risk estimates based on the available operating-system signals and current health trends.

Back up first Back up important data before acting on storage, battery, thermal, or power warnings.

Repair recommendations

04

Recommendations are generated for the specific fault detected. Examples include:

AreaRecommended action
CPUReduce sustained CPU load and inspect cooling.
MemoryClose memory-heavy applications or consider a RAM upgrade.
StorageBack up data and run SMART or disk verification for storage warnings.
ThermalClean vents and confirm fan operation for thermal problems.
DriversUpdate drivers for peripheral or adapter issues.
UpdatesInstall operating-system and security updates.
StartupDisable unnecessary startup programs.
Software faultsReview event logs and crash reports for recurring software faults.
File systemRun file-system repair after backing up important data.

After completing a repair, restart the computer and run another scan to confirm whether the fault has cleared.

Safety notes

07

SystemSentinel reports and recommends; it does not automatically delete files, change drivers, repair the file system, modify security settings, or replace hardware.

Before you repair Back up important files before disk or file-system repairs, and consult a qualified technician for critical power, thermal, storage, or electrical faults.
