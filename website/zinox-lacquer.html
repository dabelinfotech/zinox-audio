Part 1 — Installation

7 sections

Before you start

One installer per platform sets up everything — the DAW plugin formats and the standalone app install together in a single run.

System requirements
WindowsWindows 10 or later, 64-bit
macOSmacOS 10.13 or later
FormatsVST3 (Windows & macOS) · Audio Unit (macOS) · Standalone app (Windows & macOS)
AudioMono or stereo, any sample rate
RightsAdministrator/admin password required for install (writes to a shared plugin folder)
Unsigned installerZinox Lacquer isn't code-signed yet, so both operating systems will flag the installer the first time. This is expected — see the warning box in each platform's steps below for the exact click-through.

Installing on Windows

Run ZinoxLacquer-Windows-Setup.exe and follow the wizard.

  1. Run the installer

    Double-click the .exe. Windows SmartScreen will likely say "Windows protected your PC" — click More info, then Run anyway. This appears because the installer isn't signed with a paid code-signing certificate, not because anything is wrong with it.

  2. Approve the admin prompt

    Installing into the shared VST3 folder needs administrator rights. Accept the UAC prompt to continue.

  3. Choose a desktop shortcut (optional)

    The one checkbox in the wizard adds a shortcut for the standalone app. The VST3 always installs regardless.

  4. Finish

    The VST3 lands in C:\Program Files\Common Files\VST3\Zinox Lacquer.vst3; the standalone app in C:\Program Files\Zinox Lacquer\. The wizard offers to launch the standalone app immediately.

Installing on macOS

Open ZinoxLacquer-macOS.dmg and drag the bundles into your plugin folders.

  1. Open the disk image

    Gatekeeper will refuse to open it normally, since it isn't notarized. Instead, Control-click (or right-click) the app/plugin → Open, then confirm in the dialog that appears. You only need to do this once per component.

  2. Copy the plugin formats

    Drag Zinox Lacquer.vst3 into /Library/Audio/Plug-Ins/VST3/ and Zinox Lacquer.component into /Library/Audio/Plug-Ins/Components/.

  3. Copy the standalone app

    Drag Zinox Lacquer.app into /Applications.

Finding it in your DAW

Most DAWs pick up a new VST3 or AU automatically on the next launch. If Zinox Lacquer doesn't show up in your plugin list, look for a manual rescan option — it's usually under a menu named something like Plugin Manager, Preferences → Plug-ins, or Rescan Plugins, depending on the DAW. Search for "Zinox" once the scan finishes.

Activating your license

Activation is entirely offline — there's no account to create and no internet connection required.

  1. Open the license panel

    Click the badge in the top-right of the plugin window (it reads TRIAL: N DAYS LEFT before you activate).

  2. Check the Machine ID

    The dialog shows this computer's Machine ID. If you bought a machine-locked key, this is the ID you'd have sent when purchasing — it has to match for that key to work here.

  3. Paste your license key

    Paste the key you were sent into the License key field and click ACTIVATE.

  4. Done

    A confirmation names who the copy is licensed to. The badge switches to LICENSED and stays that way — the key is saved and re-checked automatically every time the plugin loads.

Moving to a new machineAn unlocked key (not tied to a specific Machine ID) works on any computer you install Zinox Lacquer on. A machine-locked key only activates on the machine it was issued for — contact support if you need it moved.

The free trial

Every install starts a genuine 7-day trial from first launch — full quality, every module and preset, nothing watermarked or held back. The badge tracks it:

TRIAL: 7D LEFT TRIAL: 1D LEFT TRIAL EXPIRED LICENSED

Once the 7 days are up without a license entered, the plugin stops processing audio — it outputs silence rather than degrading quality — and the window shows a "Free Trial Ended" screen with the license panel one click away. Entering a valid key at any point, during or after the trial, unlocks it permanently.

Uninstalling

Windows

Use Settings → Apps (or Control Panel → Programs and Features) and remove "Zinox Lacquer" — the installer registers a proper uninstaller that removes both the VST3 and the standalone app.

macOS

Remove these three items directly:

  • /Library/Audio/Plug-Ins/VST3/Zinox Lacquer.vst3
  • /Library/Audio/Plug-Ins/Components/Zinox Lacquer.component
  • /Applications/Zinox Lacquer.app

Part 2 — How It Works

6 sections

Zinox Lacquer isn't a fixed channel strip — it's a rack. The window is split into three areas.

  • Sidebar (left)

    Every module not currently in your chain, listed by name, plus the always-present Macro knobs beneath it.

  • Rack (right)

    Your active chain, rendered as narrow hardware strips left to right in processing order. Scrolls horizontally as you add modules.

  • Preset menu (top right)

    The 11 factory presets. Selecting one sets every module's knobs and which modules are bypassed; it does not change the rack order.

  • Import / Export bar (Standalone only)

    A file-processing bar across the top — absent when Zinox Lacquer is loaded as a plugin inside a DAW, since the DAW already handles import and export.

Not a fixed signal chainUnlike a conventional channel strip, the processing order in Zinox Lacquer is whatever order the modules sit in the rack, left to right. Drag a module strip's header to reorder it, drag it back to the sidebar (or click the × in its corner) to remove it, and drag a module from the sidebar into the rack to add it.

Each strip also has a small power icon next to its name, lit amber when active. Click it to mute that one module in place — its processing switches off without pulling it out of the rack or losing its position, so you can quickly A/B a module's effect without rebuilding your chain.

Rack modules

Nine processing stages, each its own hardware-styled panel with a distinct colour and a live gain-reduction meter where relevant.

Corrective EQ

Cleanup

A high-pass filter plus two broad cuts, meant to run first: clears rumble, mud, and boxiness before anything downstream reacts to it.

De-Esser

Sibilance

Split-band de-essing — only the sibilant band is attenuated, dynamically, when it exceeds the sensitivity threshold.

Compressor 1 — FET

Peak Control

A fast, punchy 1176-style compressor for taming transients before the slower opto stage smooths average level.

Compressor 2 — Opto

Glue

LA-2A-style leveling with single-knob simplicity — Peak Reduction stands in for threshold and ratio together.

Tonal EQ

Shaping

Restores presence, clarity, and air that compression tends to flatten out — meant to run after your compressors.

Saturation

Character

Harmonic warmth via three waveshaping styles — Neve, Tape, or Tube — each with its own tonal emphasis.

Delay

Space

A tempo-syncable, filtered tube-echo-style delay for vocal depth and rhythmic throws.

Reverb

Space

An algorithmic reverb with an independent pre-delay line, for placing the vocal in a room without smearing consonants.

Vocal Bus Limiter

Safety

A transparent final-stage limiter that catches stray peaks without audibly squashing the performance — meant to run last.

Macro section

Five knobs in the sidebar — Drive, Squash, High Boost, Low Boost, Mid Cut — always active regardless of what's loaded in the rack. They run once, immediately after input trim and before the rack, as a fixed console-colour stage on the source.

All five default to neutralEvery factory preset sounds exactly as documented with the Macro section untouched — it's an optional layer on top, not a required step.

Presets

11 factory presets ship with the plugin, selectable from the dropdown at the top of the window. Each sets every module's parameters and bypass state; rack order is left as you have it.

Import & export standalone only

A bar across the top of the standalone window, absent when running as a plugin inside a DAW.

  1. Import Audio…

    Opens a file picker for WAV, AIFF, MP3, FLAC, or OGG.

  2. Export Processed Audio…

    Available once a file is imported. Renders it through your current rack and Macro settings and saves the result as a new WAV file. Export runs on a background copy of your settings, so it never touches live audio, and a several-minute vocal typically renders in well under a second.

A five-minute workflow

A sensible way to build a chain on a fresh vocal take.

  1. Start from a preset

    Signature Vocal Chain is the general-purpose default — load it and listen before changing anything.

  2. Clean it up

    Corrective EQ first, to clear mud and rumble before anything else reacts to it.

  3. Control it

    Compressor 1 for transients, Compressor 2 for glue — running both lightly usually beats running one hard.

  4. Shape and colour

    Tonal EQ to restore presence, then a touch of Saturation for warmth.

  5. Add space

    Delay and Reverb, kept subtle enough to sit behind the vocal, not around it.

  6. Catch the peaks

    Vocal Bus Limiter last, as a safety net rather than a loudness tool.
