Why one strip

Six plugins' worth of chain. One instance.

A clean vocal take on the way to sounding finished usually passes through a noise reducer, an EQ, a de-esser, a compressor, a saturator, and a limiter — in that order, on every single track. Zinox Vocals runs all six stages as one signal path, already in the order they belong, so the only decisions left are which knob to turn.

Denoiser→ EQ→ De-esser→ Compressor→ Saturator→ Limiter

Inside the strip

The signal chain, stage by stage

Every stage is a real DSP implementation, running in this exact order. Push and Saturate sit inside an oversampled section so drive and harmonics stay clean at the top end.

Input

Input trim

±36 dB going into the strip — set this so Control sees a healthy signal before anything else touches it.

Denoise

Adaptive spectral noise reduction

An STFT tracker learns the noise floor in every frequency bin during quiet passages — fast to fall, slow to rise, so speech is never mistaken for noise — then subtracts it out with a spectral safety floor and smoothing to avoid musical-noise artifacts. Classical DSP, not a trained model: it excels at steady hiss, hum, fans, and room tone.

Filters

Low Cut / High Cut

24 dB/oct high-pass (20 Hz–500 Hz) and low-pass (2 kHz–22 kHz). Fully off at each knob's resting position.

Tone

Low, Mid & High bands

±18 dB per band. Low switches between peak and shelf; Mid sweeps from body at 350 Hz up to bite at 5 kHz; High picks a voicing rather than just a frequency.

De-Ess

Split-band de-essing

Threshold and ratio move together on one knob, from gentle polish through to hard taming, with an activity meter showing how hard it's working. The crossover sweeps 3 kHz–12 kHz.

Control

The main compressor

A ceiling knob — -3 / -6 / -9 — caps how much gain reduction any stage may apply, so pushing the amount never turns careless.

Parallel density and harmonic colour

Push blends a hard, fast compressor against the dry signal to raise the floor without flattening transients. Saturate adds harmonic colour, level-compensated so the knob changes character, not loudness.

Built for one job

Everything is tuned for vocals, nothing else

No generic multi-band mystery meat. Every control exists because a vocal take actually needs it.

01

Denoise that knows the difference

A continuously-learning spectral tracker removes steady hiss, hum, and room tone without chewing up consonants — no neural model, no artifacts to fight.

02

Voicings, not just frequencies

High band picks AIR, BRIGHT, or PRESENCE instead of a bare Hz number — the decision is about character, the way you'd describe it to an engineer.

03

De-essing that shows its work

One knob for threshold and ratio together, plus a live activity bar so you can see exactly how hard it's clamping sibilance.

04

A compressor with a ceiling

AGGRO, SMOOTH, or VOCAL character, with a hard cap on gain reduction so pushing the amount knob stays musical instead of squashed.

05

Push: density without flattening

A parallel compressor blended against the dry signal raises the floor while PUNCH, FAT, or TIGHT decide what happens to the transients.

06

Four distinct saturation circuits

RICH, WARM, TAPE, and TUBE are genuinely different harmonic models, not one algorithm with a tone knob — and output stays level-matched so louder isn't mistaken for better.

07

Oversampling where it matters

Push and Saturate run inside a 2×/4×/8× oversampled section, so drive and harmonics don't fold back as aliasing — trade CPU and a little latency for cleaner top end.

Standalone build

Audition a file without opening a DAW

Drop a WAV, AIFF, MP3, FLAC, OGG, or M4A onto the window, hit play, and it loops through the live processing chain to your speakers. Turn any knob mid-playback and the change is audible within a single audio block.

Export

Bounce the current settings to a new file

Export renders the imported file through whatever the knobs are currently set to, on a background thread, using a separate throwaway instance so it never disturbs what you're auditioning. Latency is compensated automatically — the output file is sample-aligned and exactly the same length as the input.
