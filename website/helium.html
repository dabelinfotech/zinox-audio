Part 1 — Installation

6 sections

One installer per platform sets up everything Helium needs — the DAW plugin formats and the standalone app install together in a single run.

System requirements
WindowsWindows 10 or later, 64-bit
macOSmacOS, 64-bit
FormatsVST3 (Windows & macOS) · Audio Unit (macOS) · Standalone app (Windows & macOS) — no AAX yet
RightsAdministrator/admin password required for install (writes to a shared plugin folder)
Unsigned installerHelium isn't code-signed yet, so both operating systems will flag the installer the first time. This is expected — see the exact click-through in each platform's steps below.

Installing on Windows

Run Helium-Setup-1.0.0.exe and follow the wizard.

  1. Run the installer

    Double-click the .exe. Windows SmartScreen will likely say "Windows protected your PC" — click More info, then Run anyway. This is because the installer isn't signed with a paid code-signing certificate, not because anything is wrong with it.

  2. Approve the admin prompt

    Installing into the shared VST3 folder needs administrator rights.

  3. Choose a desktop shortcut (optional)

    Adds a shortcut for the standalone app. The VST3 installs regardless.

  4. Finish

    The VST3 lands in C:\Program Files\Common Files\VST3\Helium.vst3; the standalone app in C:\Program Files\Zinox Audio\Helium\.

Installing on macOS

Run Helium-Setup-1.0.0.pkg and follow the installer.

  1. Open the package

    Gatekeeper will refuse to open it normally, since it isn't notarized. Instead, Control-click (or right-click) the .pkg → Open, then confirm in the dialog. You only need to do this once.

  2. Choose what to install

    The installer offers three components — VST3 Plugin, Audio Unit, and Standalone App — all checked by default.

  3. Enter your admin password

    Installing into the shared /Library plugin folders and /Applications needs it.

  4. Finish

    VST3 → /Library/Audio/Plug-Ins/VST3/. Audio Unit → /Library/Audio/Plug-Ins/Components/. Standalone → /Applications/Helium.app.

Finding it in your DAW

Look for Helium under the ZinoxAudio manufacturer tag in your plugin browser. Rescan plugins if it doesn't appear automatically.

Activating your license

Activation is entirely offline — no account, no internet connection required.

  1. Open the license panel

    Click the badge in the top-right of the plugin window (it reads TRIAL: N DAYS LEFT, TRIAL EXPIRED, or LICENSED).

  2. Check the Machine ID

    The dialog shows this computer's Machine ID, needed if you bought a machine-locked key.

  3. Paste your license key

    Paste the key you were sent and click ACTIVATE.

  4. Done

    A confirmation names who the copy is licensed to. The badge switches to LICENSED and stays that way.

The free trial

Every install starts a genuine 7-day trial from first launch — full quality, nothing watermarked or held back. The badge tracks it:

TRIAL: 7D LEFT TRIAL: 1D LEFT TRIAL EXPIRED LICENSED

Once the 7 days are up without a license entered, the plugin stops processing audio — it outputs silence rather than degrading quality — until a valid key is activated.

Part 2 — How It Works

4 sections

A 4th-order crossover splits the input at Split. Everything below passes through untouched. Everything above runs through EQ → Saturation → Compressor → Stereo Width, then sums back with the dry lows before Mix and Output.

High-End EQ

Three bands — Bite, Presence, Air — each with an independently sweepable frequency and a real peak/shelf shape switch.

Bell vs. shelfClick a band's shape switch to flip it between a bell (targets a narrow range) and a high shelf (lifts everything above the corner). Any of the three bands can be either shape.

Saturation & Compressor

Tape-style harmonic saturation and a compressor, both scoped to the same high band as the EQ.

Per-panel power buttonsEach of the three panels (EQ, Saturation & Compressor, Stereo/Output) has its own power button top-right. Switching one off bypasses just that module — the signal still flows through the rest of the chain.

Presets

Seven factory presets, selectable from the dropdown top-right (with prev/next arrows to step through them). Every preset is a normal, fully-editable starting point.
