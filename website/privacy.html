We rely on a small number of processors to run the trial signup and subscription billing:

We don't sell your data to anyone, for any reason.

3. The plugin itself

Zinox Vocals does not send any data over the network while running. License verification and the trial clock are both checked entirely offline, on your machine — there's no server we could phone home to even if we wanted to.
